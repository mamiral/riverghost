# Simulation Convergence Analysis

This directory contains scripts to analyze how Monte Carlo simulation results converge with increasing numbers of simulation runs.

## Scripts

### `simulation_convergence.py`
Runs Monte Carlo simulations for a fixed hand matchup and records win probability estimates at regular intervals to a CSV file.

**Usage:**
```bash
python simulation_convergence.py
```

**Default test case:** Pocket Aces vs Pocket Kings (should converge to ~82% win rate)

**Customization:** Edit the script to change:
- `hero` and `villain` variables for different hand matchups
- `max_simulations` (default: 250,000)
- `checkpoint_interval` (default: 1,000)
- `output_file` name

### `simulation_analysis.py`
Analyzes CSV files generated by `simulation_convergence.py` and creates convergence plots.

**Usage:**
```bash
# Analyze single CSV file
python simulation_analysis.py aces_vs_kings_convergence.csv

# Compare multiple CSV files
python simulation_analysis.py --compare file1.csv file2.csv --labels "Aces vs Kings" "Queens vs Jacks"
```

**Output:**
- PNG and PDF plots showing:
  - Win probability vs simulation count
  - Convergence (difference from final value)
  - Stability (rolling standard deviation)
  - Win probability vs time
- Console output with convergence statistics

## Example Workflow

1. **Run convergence analysis:**
   ```bash
   python simulation_convergence.py
   ```
   This will create `aces_vs_kings_convergence.csv`

2. **Analyze results:**
   ```bash
   python simulation_analysis.py aces_vs_kings_convergence.csv
   ```
   This creates `convergence_analysis.png` and `convergence_analysis.pdf`

## Key Metrics

The analysis shows:
- **Convergence point**: When the difference from final value drops below thresholds (0.01, 0.005, 0.001, etc.)
- **Stability**: Rolling standard deviation of recent results
- **Performance**: Simulations per second
- **Time to convergence**: How long until results stabilize

## Interpreting Results

- **Win Probability vs Simulations**: Should stabilize around the true equity value
- **Difference from Final**: Should decrease asymptotically toward zero
- **Rolling Std Dev**: Should decrease as more samples provide better statistics
- **Time Plot**: Shows computational cost vs accuracy improvement
